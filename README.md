# Tapestry Overlay Network Simulator

## Project Overview

Tapestry Overlay Network Simulator is a Python-based educational project developed for the subject of Distributed Computing.

It demonstrates a virtual overlay network with multiple nodes, network connections, routing tables, and message delivery between source and destination nodes.

## Features

* Display network nodes
* Display network connections
* Display routing tables
* Find a route between source and destination nodes
* Calculate the number of hops
* Display message delivery status

## Technologies Used

* Python
* Python Standard Library

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   `python tapestry.py`

## Project Type

Distributed Computing — Tiny Project

## Note

This is an educational Tapestry-inspired simulator. It demonstrates basic network routing using breadth-first search (BFS), rather than implementing the complete original Tapestry protocol.
